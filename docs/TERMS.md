# Ripple Terms of Use — Development / Hackathon Build

Effective date: 4 September 2026

Ripple is a development-stage Alexa+ add-on and MCP service created for the Amazon Developer Hackathon. By using this development build, you acknowledge the limitations below.

## Development-only service

Ripple is provided for testing and demonstration. The current public build uses simulated ride, dining, grocery, pet-care, and calendar provider integrations. It does not create real reservations, purchases, charges, calendar invitations, or other provider-side changes.

## Exact approval model

Ripple may calculate money at risk, repair cost, and net cash preserved for a demo scenario. These values are scenario inputs and product demonstrations, not financial advice, guarantees, quotations, or promises of actual savings. No repair is executed until the exact proposed plan has been explicitly approved, and execution is bounded to that approved snapshot.
